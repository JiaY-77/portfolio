### 1.2 入选标准（四条）

| 序号 | 标准 | 说明 |
| :--- | :--- | :--- |
| 1 | 开箱能用 | 无需编程、无需部署，网页或客户端注册即可使用，中文界面友好 |

- **国内方向**：服务器在境内、可直连、合规性适配政企单位，**推荐优先使用**。

### 2.2 通用助手逐个说明

#### 1）豆包（字节跳动）

- **能做什么**：日常问答、文案写作、翻译、改稿润色、图片理解与内容总结、截图与网页解析、图片生成、语音对话。
- **会做什么**：把一段粗糙草稿改写成正式文案；读懂一张截图或表格图并提取信息；用语音直接口述需求（语音识别与情绪表达接近真人）；调用内置智能体完成英语陪练、写作、编程等专项任务。
- **免费与限制**：免费版可覆盖绝大多数日常需求，主要能力不设硬门槛；专业领域深度一般，超长文本处理弱于 Kimi。
- **适合谁**：第一次接触 AI 的员工、内容与营销类岗位。

#### 2）Kimi（月之暗面）

- **能做什么**：超长文本解析（一次读数十万字的合同、财报、论文）、文件上传问答、PPT 一键生成、表格数据指令处理、联网搜索、多端同步。
- **会做什么**：把一份百页 PDF 中指定的条款原文精准定位并摘出；上传 Excel 后用中文描述需求，直接给出公式或统计结果；把文字大纲直接转成带模板的 PPT 初稿；模仿给定范文的风格改写新稿。
- **免费与限制**：网页版对话基本免费；但 **PPT 助手免费版每月仅 3 次生成**、会员 49 元/月起，高频使用需付费——**已不适合作为重要交付的首选**（2026-09-19 复核）；高峰时段可能排队。
- **适合谁**：需要处理长文档、做汇报材料的岗位（几乎人人适用）。

#### 3）通义千问（阿里巴巴）

- **能做什么**：文档撰写与处理（Word / Excel / PDF）、图片理解（国产模型中最强）、多模态推理（看草图、看图表、生成教学示意）、数据整理与公式、网页与 App 双端。
- **会做什么**：把一份 Excel 表整理成规范表格并给出分析结论；看懂手绘草图或数据图后回答问题；生成结构化的公文与方案初稿；配合钉钉 / 阿里云生态完成办公任务。
- **免费与限制**：基础对话与文档处理免费；更高阶能力与额度需付费订阅。
- **适合谁**：办公文档密集岗位、需要「看图说话」的岗位，以及钉钉生态用户。

#### 4）腾讯元宝（腾讯）

- **能做什么**：对话问答、长文与公众号内容总结、图片解析、文档写作，与微信 / QQ / 腾讯文档打通。
- **会做什么**：把微信里转发的长文章一键总结成要点；在腾讯文档内直接调用 AI 起草与改写；整理群聊信息与会议要点。
- **免费与限制**：免费使用；视频生成等能力弱于豆包、通义，专业深度一般。
- **适合谁**：日常依赖微信与腾讯文档办公的岗位。

#### 5）DeepSeek（深度求索）

- **能做什么**：深度推理、数学计算、数据分析推演、代码辅助、长文本阅读、联网搜索、文件上传。
- **会做什么**：把一堆散乱的业务数据整理成有逻辑的分析结论；按条件推导公式或计算规则；解释一份陌生材料背后的逻辑；给出多种方案并说明取舍。
- **免费与限制**：网页版与 App 免费；免费版联网搜索不展示来源链接（只能用结论、不便查证）；高峰时段可能繁忙。
- **适合谁**：需要「想清楚」而不是「写漂亮」的岗位，如分析、财务、流程优化。

#### 6）文心一言（百度）与智谱清言（智谱 AI）——补充

- **文心一言**：中文写作与知识问答扎实，背靠百度搜索与知识图谱生态，适合查资料与写公文初稿。

## 三、海外 AI 工具（能力上限更高，需合规通道）

### 3.1 前置说明（重要）

1. **地区限制**：OpenAI（ChatGPT）、Google（Gemini）、Anthropic（Claude）的官方支持地区清单**均不含中国大陆、香港、澳门**；Google 官方表述为「中国大陆（仅限 Workspace）」。官方明确警告：从不支持地区访问或为其提供访问服务，账号可能被封锁或暂停。
2. **合规要求**：访问海外服务需遵守所在地区法律法规与单位网络安全规定，**须经单位 IT 部门评估的合规通道**，个人自行配置的方式不建议用于工作场景。
3. **数据出境**：海外工具的对话数据默认可能被用于模型训练（各家可关闭，条款不同）。**敏感数据不得上传**，海外工具仅用于公开信息加工与创意类工作。
4. **结论**：海外工具作为「了解与进阶参考」，有条件、有需要的岗位在合规前提下使用；**日常提效以国内工具为主**。

### 3.3 通用助手逐个说明

#### 1）ChatGPT（OpenAI）

- **能做什么**：全场景写作与改写、信息总结、翻译、数据分析与公式、代码、图片生成、图片与文件上传理解、深度研究、语音对话、Canvas 可视化编辑。
- **会做什么**：把会议记录整理成结构化纪要；按指定结构（PREP/STAR/SCQA）输出汇报；上传表格后给出计算逻辑与结论；根据描述直接生成配图；用它自带的优化功能把一句粗糙指令改写成规范提示词。
- **免费与限制**：免费层使用主力模型但有额度限制（公开资料：约每 5 小时 10 条，用完后自动降级到轻量模型，窗口刷新后恢复）；美国区免费账号在部分回答底部会显示广告；最新旗舰型号为付费专属。

- **隐私**：**默认用对话训练模型**，需在设置中手动关闭。

#### 2）Gemini（Google）

- **能做什么**：强推理、超长上下文（旗舰版约 100 万 token，约等于上千页文本）、深度研究、图片生成、Google 生态集成（Docs / Sheets / Gmail / Slides 内直接调用）、多模态理解。
- **会做什么**：把一份长报告连同数据一起分析并给出结论；在 Google 文档里直接起草与改写；用图片生成能力做配图与视觉稿；做一次带引用的资料研究。
- **免费与限制**：免费层使用轻量档模型 + 部分旗舰模型访问权；深度研究每月有次数上限；**视频生成（Veo）属付费能力**，免费层不含。

- **免费与限制**：免费层使用中档模型，采用**滚动用量预算**（公开实测约每 5 小时 15–40 条，随负载波动），额度内体验接近付费。

- **隐私**：**是否用对话训练由用户选择，默认不训练**，数据保留 30 天——三家主流助手中隐私条款最友好。

#### 4）Microsoft Copilot（微软）

- **能做什么**：对话问答、**图片生成**（底层为 DALL·E 3）、Office 文档与邮件辅助（Word / Excel / PowerPoint / Outlook 内调用）、Windows 与 Edge 内置。
- **会做什么**：在 Word 里直接起草与改写；在 PowerPoint 里根据一份 Word 文档生成演示初稿；在 Excel 里用自然语言生成公式；免费生成配图。
- **免费与限制**：个人版免费，**图片生成基本不限次数**（生成速度随额度变化但不会停）；Office 内的深度集成能力需要 Microsoft 365 Copilot 订阅。
- **适合谁**：已在使用微软办公套件、又需要免费配图的岗位。

#### 5）Perplexity（资料检索）

- **能做什么**：搜索式问答，答案**逐条附来源链接**，可直接跳转原文核验。
- **会做什么**：快速摸清一个陌生领域；查一条信息的出处；比较几个方案时给出带引用的对比。
- **免费与限制**：免费层使用其自有模型，每天有少量高级搜索次数；选择顶级模型搜索属付费能力。
- **定位**：不是写材料的工具，而是**查证与调研**的工具，正好补上通用助手「来源不可查」的短板。

## 四、海内外同场景对比（一页结论）

| 场景 | 国内首选 | 海外对应 | 差距与选择建议 |
| :--- | :--- | :--- | :--- |
| S1 文档撰写 | 豆包 / 腾讯元宝 | ChatGPT / Claude | 中文公文与本土表达国内更贴；长文逻辑与「不像 AI 写」的手感海外更强 |
| S2 PPT 制作 | 讯飞智文 / WPS AI | Canva / Gamma | 国内模板更贴国内场景；海外设计感与速度更好，但免费层导出 PPTX 常受限 |
| S3 Excel 处理 | 通义千问 / DeepSeek | ChatGPT / Copilot | 公式与统计双方都能胜任；Copilot 的优势在与 Excel 原生集成 |
| S4 图像生成 | 通义万相 / 豆包 | Copilot Image Creator / Nano Banana | 免费额度国内更宽松；写实质量与图中文字渲染海外领先 |
| 资料检索 | 通义 / 文心（联网） | Perplexity | 海外工具**答案带来源可查证**，是最大差异点 |
| 内部流程协同 | 钉钉 AI | Copilot（M365） | 国内可直接嵌入现有协作平台，无切换成本 |

**一句话结论**：**日常提效以国内工具为主（可直连、合规、免费够用）；海外工具在推理深度、创意质量、来源可查证上有优势，作为有条件岗位的进阶选项，不作为普遍推荐口径。**

## 五、落地建议

1. **工具矩阵按「国内 / 海外」两页呈现**，每页四张卡对齐四大场景（文档 / PPT / Excel / 图像），每卡 1 个首选 + 1 个备选，不做全量罗列。
2. **现场可扩展讲**：每款工具只讲「一个最拿得出手的能力 + 一个必踩的坑」，细节留 QR 码 / 手册。
3. **红线先行**：讲工具前先讲数据安全三条红线（机密不外传 / 内容必复核 / 不替代判断），海外部分额外补「地区限制 + 合规通道 + 数据出境」。
4. **统一话术**：功能描述不带版本号轰炸，一句话说清「它替人干什么活」。
