- **[TriviumDB 依赖升级与上游贡献](docs/TriviumDB%20依赖升级与上游贡献.md)**
  隔离 venv 的 A/B 压测与零迁移验证、性能回归定位与上游 issue / PR，以及一个被我自己撤回的结论。
  关注点：**怎么保证一次依赖升级不出事**——以及数字站不住时敢不敢撤回。
